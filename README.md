## what:

a cross-platform (linux and macos silicon included!!) extension for vscode and vscodium to help with making mods

## when:

now !!

## where:

here !! and both ([open-vsx.org](https://open-vsx.org/) and [marketplace.visualstudio.com/vscode](https://marketplace.visualstudio.com/vscode)) marketplaces!!

## how:

- workspace wide uuid/handle replacement
- "add as handle" to xml file
- xml merge support
- multi-mod workspace support
- conversion for \*.ls{b, bc, bs, efx, f, fx, x} files to and from editable and binary formats
- pack and unpack mods
- game data unpacking
- version editing

## why:

because modding this game on linux and other platforms needed some love <3
